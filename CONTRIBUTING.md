# Contributing

- Read the README and `docs/` first. The local-first and read-only-platform rules are not negotiable.
- Every behaviour change comes with a test (`pytest`). Event format changes need a rebuild test.
- Keep the core free of third-party dependencies (ADR 0001).
- Record decisions that change a rule as an ADR in `docs/adr/`.
- Achievement packs are welcome as separate repositories under CC0-1.0 or another open licence.
