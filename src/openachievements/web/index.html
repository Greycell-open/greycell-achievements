Greycell Achievements

Every game deserves achievements.

One library for Steam, RetroAchievements, and the games no platform tracks: DRM-free copies, old installs, emulators, your own challenges. It keeps working offline, it is yours to export, and you can run it on your own server.

At least 10 characters. It is stored only as a scrypt hash.

  • Local first. Your profile is a folder of plain JSON on your own computer. This server is a copy, never the only one.
  • Free, forever. Open source, no ads, no selling your data, no premium tier.
  • Honest. Every unlock says where it came from: imported from a platform, played, or read from a save. Nothing is ticked by hand.
